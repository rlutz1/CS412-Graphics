## texture mapping

+ square is pretty straightforward
+ cylinder too, but need to either crop or warp the top/bottom
+ sphere is a pain

uv mapping -- texture map in a parametric form

texture mapping -- texture map with x, y, z

typically in industry -- have a 3d model and a 2d rectangle image and they map is specifically

texture is defined in its own coordinate system for the start
+ a normalize coordinate system (0, 0), (1, 1)
+ you're kinda mapping in such a way where you're wrapping the primitive in a rotating traversal

forward mapping
+ we know the uv and essentaially looking up the pixel that corresponds to the correct texture point
  + a lookup table to figure out the rgb value this uv should be
backward mapping
+ really the gpu uses this mapping

need to scale the mapping according to your cube size -- considering the texture is (0, 0), (1, 1)
