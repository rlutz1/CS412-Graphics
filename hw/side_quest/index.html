General Breakdown of Submission

The following canvas builds off the "cake" structures built in the last homework.
The left-most structure implements flat shading, the structure
in the middle implements Gouraud shading, and the right-most implements
Phong shading.

Animate with Time
Select the "Animation Mode" check box to see the structures move with time.
More, finer-tuned controls are discussed below.

Changing Material
Select the "Change Material" accordian button to see how the cake material
can be updated. All values of the materials were taken from this source.
The scene nodes are given a baseline color of [0.5, 0.5, 0.5] and all coefficients are
used accordingly in the shaders (found in vert_shaders.js and frag_shaders.js).
A radio button selection will set the coefficients common to that material and also update the
sliders to those default values. If the sliders are used, the radio selection is ignored
until the radio buttons are interacted with again.

Adding/Removing Lights
Select the "Adding/Removing Lights" accordian button to play with adding point lights
to different global positions in the scene. You can add up to 50 point lights
which is a limit imposed by an array size in the shaders (avoiding overflow issues).
Removing the lights will remove the first occurrence of that light's position in the
global light list. The id's are arbitrary, and mostly to provide visual feedback that
There is more than one light, despite the same position.

Move Segments
Select the "Move Segments" accordian button to play with the dynamic rotations
of each segment of the hierarchical structure. These are the same rotation
matrices used in the animation mode over time, but this gives you the ability
to move these separately.
